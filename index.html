这个智能体在解决什么问题
固态电解质文献量庞大、跨论文性能口径不一致（同一 Li6PS5Cl 的电导率在不同论文间可差 2–3 个数量级）。本系统把"读文献→找空白→提假设→出路线"这条科研闭环，做成了证据可回溯、每步可复跑、审计可抓错的确定性流水线。

两层架构：确定性证据层 + AgentScope 认知层

层职责实现
数据 / 审计层检索、筛选、全文、结构化抽取、单位归一化、矛盾检测、报告、审计自研 Python 标准库，零第三方依赖
认知层Research Gap → 假设生成 → 候选路线 → 反证收缩（discover 循环）AgentScope 2.0（唯一运行时依赖）
★ 核心设计：证据链 doc_id → record_id → 全文内容 全程可回溯；追加式增量写入；硬预算上限（LLM 1200 / Sciverse 3000 / Materials Project 100）。

一句话成果

在 778 篇文献上跑通检索→抽取→知识融合→科学发现→报告全闭环，产出 19 个 Gap、20 条假设、12 条路线；跨文献矛盾检测把同配方电导率 2–3 个数量级的分散量化成了 85 条可追溯矛盾对；证据链自检修复后 audit 判定 PASS。

以 discover 循环自主产出的 gap_012 为例：从两条独立文献证据识别出"从未被联合探索"的维度，生成可证伪假设，并落到一条可执行路线。
Research Gap · gap_012

多价阳离子晶界掺杂 × 富卤/混卤，两轴从未联合

文献已分别报道"Ca²⁺/Y³⁺ 晶界掺杂改善界面"与"富卤素/混卤提升体相无序"，但两条机理互补的掺杂轴从未在同一体系联合报道。

依据 record：rec_310 · rec_345 · rec_287
→
Hypothesis · hyp_013

晶界 Ca²⁺/Y³⁺ 掺杂 + 体相 Cl/Br 混卤协同

假设：在 Li6PS5Cl₁₋ₓBrₓ 上引入晶界 Ca/Y 掺杂，同时提升体相电导率与界面稳定性（可证伪：预期电导率与湿度耐受相对单因素均提升）。

linked_gap：gap_012
→
Route · route_E

Ca/Y 共掺混卤 argyrodite 的球磨 + 退火路线

给出前驱体配比、球磨参数、退火窗口与测量口径（含温度标签），每步锚定原文证据，可直接作为 DOE 湿实验协议输入。

倒推：hyp_013 → gap_012 → rec_310/345/287

这条链为什么可信

性质保证机制
证据可回溯每条 gap/假设/路线的 evidence_doc_ids 经修复后与 records 真实 doc_id 完全一致（mismatch = 0）
不夸大新颖性反证收缩先查先例，把"生成看似新颖配方"收敛为"严格证据边界下的可证伪假设"
口径可比路线强制带测量温度标签，避免跨论文性能误判
审计、修复与诚实披露
本系统把"审计自身"也做成了确定性流程，并如实披露修复过程——纠正而非掩盖。

三条红线（本系统的自我约束）

① 候选 Gap/假设/路线均为待证伪假设，不对应湿实验性能保证；② 不为了 PASS 而放宽审计，相反把"审计漏掉的问题"补进审计；③ 矛盾检测为未对齐测量温度的初筛，数值仅用于领域聚焦度自评估。
